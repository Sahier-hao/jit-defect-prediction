# 文档导航：Sprint 0 先看这里

整理日期：2026-10-06。当前目标是完成需求与产品设计初版、项目管理看板及 OpenSpec 初始材料。以下材料可供团队修改，尚未替团队确认范围或通过验收。

## 第一次阅读，只走这条路线

1. [项目一页概要](团队协作/项目一页概要.md)：我们给谁做什么工具。
2. [产品需求文档](需求与设计/产品需求文档.md)：用户、场景、竞品或替代方案、MVP 与第一轮范围。
3. [产品设计文档](需求与设计/产品设计文档.md)：架构、数据库与时序；搭配[核心流程](需求与设计/核心流程设计_中英.md)和[低保真原型](需求与设计/原型/低保真原型.html)。
4. [Sprint 0 任务与评审清单](团队协作/Sprint0前置工作清单.md)：认领任务、记录意见与成果。
5. [Sprint 0 OpenSpec 提案](../openspec/changes/establish-product-baseline/proposal.md)：核对工程基线的 proposal、规格与任务。

原型 HTML 可直接在浏览器打开；Markdown 可在编辑器预览。暂时无需安装 Python 或 Node 才能阅读这些材料。
