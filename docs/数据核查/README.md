`activemq-2024-sample-20261004/` 保存原始公开响应与来源清单；其他示例、结果目录保存输入和不可覆盖的快照。原始来源、示例与快照保留现有路径，便于复核，不作为已完成 SZZ 或真实模型效果的证明。

本目录内以“验证记录.json”结尾的文件是当时的检查证据；当前目录整理检查见[验证记录导读](../验证记录/README.md)。

在项目根目录执行以下共享工具，可以离线核对保存的来源与快照：

```powershell
python scripts/verify_data_sources.py
python scripts/verify_saved_evidence.py
```

以上复核不采集网络数据、不执行 Git、不训练模型，也不修改历史快照。
