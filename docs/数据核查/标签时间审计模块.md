# 标签时间审计与基线训练

日期：2026-10-05。对应[变更计划](../../openspec/changes/audit-temporal-label-availability/proposal.md)。本轮把“标签在训练截止前可得”落成可执行校验，未完成真实SZZ、仓库特征或产品评审。研究依据与回溯／连续评价区别见[调研记录](标签延迟与时间切分调研_20261005.md)。

## 当前行为

普通CSV仍按原14维格式导入。合成演示仍能训练；元数据增加 `label_availability_checked=false`、`label_time_policy=unchecked_synthetic_only`。普通**非合成**CSV即使满足1000条和50个正标签，也不能通过现有API直接训练；缺少时间契约时返回422，不登记模型、不写模型文件。小样本仍先报原数量门槛。

新增 `fit_temporal_baseline(csv_bytes, contract_bytes, is_demo=False)` 离线Python入口，会在内部重新绑定与审计输入，再训练准入行。现有API尚无契约上传／持久化入口；此限制明确保留，不通过改合成标记来声称真实数据已验收。

## 时间契约

输入为[合成CSV](标签时间合成示例/synthetic-features.csv)与[合成时间契约](标签时间合成示例/synthetic-contract.json)。契约需要：

| 字段 | 规则 |
|---|---|
| `formatVersion`、`kind` | 精确版本1，类型 `temporal_label_contract` |
| `csvSha256` | 原CSV精确字节的SHA-256；改空行也需重新审计 |
| `config.trainCutoff` | 带时区的训练截止；提交严格早于该时点才属于训练队列 |
| `config.evaluationCutoff` | 严格晚于训练截止；测试提交位于两者的左闭右开区间 |
| `config.maturityDays` | 显式整数1–3650，不接受布尔值、0或隐式默认 |
| `rows[].commitId` | 与CSV提交ID逐条完整对应，不缺失、不多余、不重复 |
| `featureAsOf` | 该向量的历史信息截止，必须与提交时点一致；不是脚本运行／下载时间 |
| `labelStatus` | `buggy`／`clean_observed`／`unknown`，分别对应CSV的1／0／unknown |
| `labelAvailableAt` | 标签历史可得时间；不能早于提交时点；缺失则显式排除 |
| `evidenceRef` | 供复核的引用；缺失则显式排除，尚未自动认证对应来源 |

时间统一为UTC；CSV限制5MiB／20,000行，契约限制8MiB／20,000行。重复JSON键、额外字段、无时区、错误哈希、标签不一致、ID覆盖问题或不可能的标签先于提交都会使整个审计失败。无标签、无时间或无引用则保存逐行排除理由。

## 队列和过滤

先按提交时间固定队列，然后过滤，不重新计算70/30边界。同时间戳整体同侧；等于训练截止的提交属于测试队列。训练标签可得时间须不晚于训练截止；测试标签须不晚于评价截止。**标签检查允许等于截止**，这是一项明确工程约定，不隐含更细事件顺序已得到证明。

负例要求证据可得时已覆盖提交后的成熟期：`labelAvailableAt >= committedAt + maturityDays`。若声明的负例证据出现过早，即使今天已经过去足够久，也不自动补成成熟证据。零标签只表示给定窗口内未发现归因，不表示永久无缺陷。

每条决策保留提交、队列、标签检查截止、声明的信息／标签时间、标签状态、引用和理由。首个失败条件作为主理由；没有自动枚举同一行所有问题。迟到的当前正例不回填为过去的正例，也不臆造过去负例；历史标签修订尚未重构。

## 复现

审计CLI仅使用Python标准库：

```powershell
python -m jit_defect.temporal_audit --csv docs/数据核查/标签时间合成示例/synthetic-features.csv --contract docs/数据核查/标签时间合成示例/synthetic-contract.json --snapshot-dir docs/数据核查/标签时间审计结果
python -m jit_defect.preparation_batch verify --snapshot docs/数据核查/标签时间审计结果/4a86d1a4266b3b0db23c8e7c0022b47a8391df488d6f43b84ca4fdaf0d3d8691.json
```

成功退出0，输出计数和快照摘要；失败退出2、stdout为空、stderr说明原因，不发布部分快照。内容寻址与不可覆盖发布复用[已有模块](批量准备与快照.md)。

在已安装项目机器学习依赖的Python环境中，离线调用示例：

```python
from pathlib import Path
from jit_defect.learning import fit_temporal_baseline

example = Path("docs/数据核查/标签时间合成示例")
result = fit_temporal_baseline(
    (example / "synthetic-features.csv").read_bytes(),
    (example / "synthetic-contract.json").read_bytes(),
    is_demo=True,  # 本例是合成软件夹具，不能当作真实实验
)
print(result.metadata["train_count"], result.metadata["test_count"])
```

新入口只用准入训练行拟合Scaler和分类器，只评价准入测试行；被排除行不输出预测。数量门槛在过滤后判断，仍为非合成模式1000条／50正例、合成20条，训练必须两类且测试非空。模型元数据保留完整审计报告、固定截止、排除数、输入哈希，并区分“声明已检查”与“上游来源已认证”。本例模型计算用于软件行为检查，不给出精度／AUC等真实效果结论，也不登记到Web数据库。

本轮[验证记录](标签时间审计验证记录.json)保存新增测试、完整回归、来源和旧快照复核结果。原15份来源及旧准备快照不改写；需求、设计和README等活动文档随新实现更新，旧验证记录仍是各自时点的历史记录。

## 真实数据前还缺什么

`evidenceVerification=caller_supplied_requires_source_review`：本模块不能阻止调用方编造历史声明，不能仅凭一个CSV哈希证明14维特征或SZZ质量。审计快照始终 `trainingReady=false`。真实运行还需要归因／标签事件来源、分支与祖先验证、特征口径和历史版本核查，以及小组真实评审。成熟期需按仓库Pilot；完整标签修订、在线更新、跨项目比较与契约API持久化仍未实现。
