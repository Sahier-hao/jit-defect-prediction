## 用例覆盖

- 输入：14 维必填特征、非法值、非有限数、负数、fix 与 label 的范围、UTC 归一、缺失表头、重复 ID、BOM、文件／行数限额。
- 学习：同一时间点不跨集合、无法切分的时间数据、unknown 排除、标准化仅拟合训练集、真实数据模式最小样本量、训练仅一类时失败。
- 评价：可手算的 AUC／Popt／预算 recall、零成本归一、无正样本和单类测试集、预算不能跳过第一条昂贵提交。
- 解释：全部贡献加截距能够通过 sigmoid 重建同一概率；方法标为 linear_log_odds。
- 服务：空工作区、导入失败原子性、版本不覆盖、重启读取、全局分页排序、筛选、训练／测试期标识、跨数据集错误、缺失 ID、示例幂等、损坏模型文件。
- 界面：示例导入、实际模型训练、两类指标、详情、过滤为空、上传 CSV、刷新恢复、失败表单保留错误、手机端详情按钮水平可见、没有整页横向溢出。
- 请求竞争：延迟上一数据集的实际接口响应，快速切换后不会覆盖当前模型。
